# To-do

Personal to-do PWA (TypeScript, React, Vite). See GLOSSARY.md and docs/adr/.

## Scripts

- `npm run dev` - local dev server
- `npm test` - run Vitest
- `npm run build` - type-check and production build (outputs `dist/`, including manifest and service worker)
- `npm run preview` - serve the production build locally

## Deploying to Vercel

1. Import the GitHub repo at vercel.com/new (free tier is fine).
2. Vercel reads `vercel.json` (Vite framework, `npm run build`, output `dist`). No other settings needed.
3. Deploy, then open the URL on a phone or desktop and use "Install app" / "Add to Home Screen".

Icons in `public/` are generated by `node scripts/make-icons.mjs`.
